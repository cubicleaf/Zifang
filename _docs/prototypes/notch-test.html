NORMAL COLORS (subtle but real)

因為

yīnwèi · because
Example Sentences
因為下雨，所以我不去。
Yīnwèi xiàyǔ, suǒyǐ wǒ bú qù.
Because it's raining, I'm not going.
我很累，因為今天工作很多。
Wǒ hěn lèi, yīnwèi jīntiān gōngzuò hěn duō.
I'm very tired because there was a lot of work today.

幫助

bāngzhù · to help
Example Sentences
你可以幫助我嗎？
Nǐ kěyǐ bāngzhù wǒ ma?
Can you help me?
謝謝你的幫助。
Xièxiè nǐ de bāngzhù.
