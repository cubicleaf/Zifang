# Zifang files

`index.html` is the live app. `moria.html` and `moria/` are a separate companion surface. `data/` holds app data, and `scripts/`, the root `migrate.js`, and the root `upload-*.js` files are operational code with existing path assumptions; they were left in place.

Read `INTENT.md` for the app's doctrine and `STATUS.md` for current decisions. `markdowns/` holds current instructions and app guidance; `_docs/` holds preserved HSK research, audits, proposals, prototypes, snapshots, and captures. Each has a `README.md` map. The `old images/` folder is retained unchanged.
