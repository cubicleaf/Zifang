# Zifang files

`index.html` is the live app. `moria.html` and `moria/` are a separate companion surface. `data/` holds app data, and `scripts/`, the root `migrate.js`, and the root `upload-*.js` files are operational code with existing path assumptions; they were left in place.

Read `INTENT.md` for the app's doctrine and `STATUS.md` for current decisions. `markdowns/` holds project instructions, design notes, and research; `_docs/` holds preserved audits, prototypes, snapshots, and captures. The `old images/` folder is retained unchanged.
