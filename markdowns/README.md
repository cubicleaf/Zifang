# Zifang working documents

These are the current instructions and reference surfaces for Chinese learning and Zifang development:

- `PROJECT_INSTRUCTIONS.md` — personal learning modes and output rules; `PROJECT_INSTRUCTIONS_PORTABLE.md` is its portable version.
- `chinese-hub-knowledge.md` — learning and correspondence context; `personas/` holds the named modes.
- `zifang-design-system.md` — app architecture and design guidance.
- `zifang-project-knowledge.md` — app context; `zifang-pending-queue.md` — feature backlog.

Historical audits, HSK pipeline research, completed prompts, and design explorations are preserved in the project-level [`_docs/`](../_docs/README.md). Start with [`INTENT.md`](../INTENT.md) and [`STATUS.md`](../STATUS.md) for the project's current direction.
