## 🔴 Critical — Fix Immediately

### 1. Example schema split breaks 140 cards in the app
**Cards affected:** IDs 5971–6110 (the most recently enriched batch)
**What happened:** Earlier enrichment sessions stored examples as `{chinese, pinyin, english}`. A later session switched to `{sentence, translation}`. The app (index.html line 9485) only reads `ex.chinese` and `ex.english` — no fallback. Result: all 140 cards in IDs 5971–6110 **render blank examples in the UI right now.**
**Fix options (pick one):**
- A) Update `index.html` line 9485 to: `ex.sentence || ex.chinese` and `ex.translation || ex.english`
- B) Migrate the 140 affected DB records to rename `sentence→chinese`, `translation→english`
- Option A is a one-line fix. Option B cleans the data permanently but requires a migration script and loses pinyin (which the new schema didn't include anyway).
**Priority: fix before next enrichment session.**

### 2. ID 5171 不止 — Factual error (wrong word's definition imported)
**Issue:** Enriched `english` field includes "not only" — the meaning of 不只 (bùzhǐ), a completely different character and word. 不止 (bùzhǐ) means "more than; incessantly; without stopping." The semantic note correctly explains the real senses, but the headline definition contains a foreign meaning.
**Fix:** Remove "not only" from the english field. Correct definition: `more than; incessantly; without stopping`.

### 3. 于/於 errors — 3 cards with simplified character in traditional fields and examples
The enrichment pipeline let mainland-standard 于 slip through instead of Taiwan-standard 於 in three cards. Both the `traditional` metadata field AND all example sentences are affected (6 sentences total).

| ID | Simplified | Traditional field (wrong) | Should be |
|----|-----------|--------------------------|-----------|
| 5735 | 过于 | 過于 | 過於 |
| 5861 | 急于求成 | 急于求成 | 急於求成 |
| 5922 | 鉴于 | 鑒于 | 鑒於 |

**Fix:** Update both the `traditional` field and all example sentences for these three cards in Supabase and in the local batch-02.json.

### 5. 11 apostrophe violations in HSK5 enriched cards (systematic LLM artifact)
All 30 enriched HSK5 cards were generated by a model that never inserts apostrophes before syllables starting with a/e/o. Every violation is in this batch.

| ID | Simplified | Current pinyin | Correct |
|----|-----------|---------------|---------|
| 2561 | 从而 | cóngér | cóng'ér |
| 2659 | 反而 | fǎnér | fǎn'ér |
| 2666 | 方案 | fāngàn | fāng'àn |
| 2668 | 妨碍 | fángài | fáng'ài |
| 2994 | 恋爱 | liànài | liàn'ài |
| 3105 | 平安 | píngān | píng'ān |
| 3139 | 亲爱 | qīnài | qīn'ài |

### 6. Particle deck: 26 cards with zero examples, 5 with one

### 8. Sense-priority drift — 5 cards
The enriched `english` field promotes a modern/figurative sense to headline, dropping the primary sense the HSK source intends. The semantic note often mentions the dropped sense, but the headline definition misleads HSK exam students.

| ID | Word | HSK source says | Enriched says | Problem |
|----|------|----------------|---------------|---------|
| 5271 | 澄清 | settle (liquid); become clear; (Chem.) precipitate | to clarify; clear up (a misunderstanding) | Literal/chemical senses completely dropped |

| 5741 | 寒暄 | exchanging greetings; winter and summer | exchange pleasantries | Etymological sense ("winter and summer") dropped — minor, archaic |

**Fix:** Restore the primary HSK sense to the `english` field for 5271, 5121, 5361, 5631. These don't need full regeneration — surgical edits to the english field only.

### 9. POS taxonomy is not unified across decks
126+ distinct POS label forms exist across the database. Different decks were enriched at different times with different schemas:

| Deck | Style | Example |
|------|-------|---------|
| HSK1 | Short-form | `mw`, `adj/adv` |
| HSK2 | Comma-separated | `adj,adv`, `adj,prep,verb` |
| HSK3 | Full English + slash | `adjective/adverb` |
| HSK4 | Mixed | `adj/adv`, `determiner` |
| HSK5 | Full English, no combos | `noun`, `verb` |
| HSK6 | Full English + space-slash | `adjective / verb` |

82 cards also have the literal string `"None"` as their POS value (Python None serialized incorrectly).

**Recommended canonical set:** `v`, `n`, `adj`, `adv`, `conj`, `prep`, `pron`, `mw`, `particle`, `idiom`, `phrase` — with slash for dual function (e.g., `v/n`).
**Fix:** A normalization script mapping existing values to canonical forms, run against the full database.

### 10. HSK6 pinyin spacing inconsistency
- **Chengyu:** 7 of 52 four-character chengyu use spaces between syllables; 45 don't. (e.g., `jù jīng huì shén` vs `àibúshìshǒu`)
- **Short verb-object words:** 35 HSK6 words use spaces (e.g., `jiù zhí`, `kuàng kè`) while HSK5 never spaces two-character words.
**Fix:** Decide on a convention (recommended: no spaces within a word, spaces only for set phrases that are conventionally written with spaces) and normalize the outliers.

## 🟢 Low Priority / Noted Only

### 11. Productive expansions are unlabeled
Several cards add modern senses not in the 2012 HSK source: 穿越 (time-travel fiction), 動態 (social media status update), 訪問 (website visit), 科目 (accounting categories). These are **accurate and useful additions for Taiwan learners** but are presented without any "(modern)" or "(extended)" marker. A learner studying for the HSK exam can't distinguish these from the tested senses.
**Suggestion:** Prefix such senses in the semantic note with "(modern usage:)" or "(colloquial:)".

### 12. Grammar sophistication gap in HSK6 examples
HSK6 vocabulary is appropriately C1, but the grammar in example sentences is mostly HSK3-4 level (simple SVO). For a vocab deck this is defensible, but it means learners won't see advanced connective structures, pivotal sentences, or complex subordination in context.
**Not an error.** Worth a deliberate second-pass for a "rich" depth tier if that's ever built.

### 13. Minor definition narrowings (stylistic, not errors)
- **5141 剝削:** "to exploit (labor)" — "(labor)" unnecessarily narrows to Marxist context only
- **5301 初步:** "initial; preliminary" — "tentative" (from HSK source) dropped
- **5421 典禮:** "ceremony" — "celebration" (from HSK source) dropped
- **5471 隊伍:** "troops" sense dropped, replaced with "line" (informal)
These are judgment calls, not factual errors. Fix only if comprehensiveness is a priority.

### 14. 啓/啟 character variant (ID ~6412)
Card uses 啓 (U+5553) in the traditional field; examples use 啟 (U+555F). Both are valid traditional forms but string-matching fails. Should normalize to one variant (啟 preferred in Taiwan).
