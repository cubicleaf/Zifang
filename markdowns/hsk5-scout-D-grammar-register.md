## 1. Separable Verbs (離合詞 V-O compounds)

These are verbs whose two characters are actually verb + object grammatically. Aspect markers (了/过/着), measure phrases, modifiers, and reduplication go BETWEEN the two characters, not after them. Wrong form (e.g., "结婚了三次") sounds non-native.

| Simplified | Category | What the semanticNote MUST mention | Example use |
|---|---|---|---|
| 离婚 | Separable V-O (离 leave + 婚 marriage) | Splittable; aspect/duration goes between. Cannot say *离婚了三次. | 他离过两次婚。/ 他们离了婚。 |
| 结账 | Separable V-O (结 settle + 账 bill) | Split for objects/aspect: 结一下账, 结过账. | 我们结一下账。/ 还没结账呢。 |
| 上当 | Separable V-O (上 fall for + 当 trick) | Split: 上了当, 上过一次当. Never *上当了一次. | 我上过一次当。 |
| 倒霉 | Separable V-stative (倒 turn + 霉 mildew) | Splittable: 倒了霉, 倒什么霉. | 今天真倒霉。/ 倒了大霉。 |
| 吃亏 | Separable V-O (吃 eat + 亏 loss) | Split for aspect/quantity: 吃了亏, 吃过亏, 吃大亏. | 他吃了一次大亏。 |
| 操心 | Separable V-O (操 exert + 心 heart/mind) | Split: 操什么心, 操了一辈子心. Object follows 为/给, not 操心. | 别操这个心了。/ 妈妈为他操了一辈子心。 |
| 拐弯 | Separable V-O (拐 turn + 弯 bend) | Split: 拐个弯, 拐了一个弯. Use 拐弯 intransitively or split it. | 前面拐个弯就到了。 |
| 握手 | Separable V-O (握 grasp + 手 hand) | Split: 握了握手, 跟他握手 (object via 跟/和, not after). | 他跟我握了握手。 |
| 流泪 | Separable V-O (流 flow + 泪 tear) | Split: 流着泪, 流了几滴泪. | 她流着泪说话。 |
| 受伤 | Separable V-O (受 receive + 伤 injury) | Split: 受了伤, 受过重伤. Never *受伤了腿 — use 腿受伤了. | 他在车祸中受了伤。 |

| 干活儿 | Separable V-O (干 do + 活儿 work) | Split: 干了一天活儿, 干过这种活儿. | 他干了一天活儿。 |
| 告别 | Separable V-O (告 inform + 别 part) | Object via 跟/和: 跟父母告别. Split: 告了别, 告过别. | 他跟家人告了别。 |
| 结婚 | Separable V-O (结 tie + 婚 marriage) | Split: 结过婚, 结了三次婚, 结什么婚. Never *结婚了三次. | 他结过两次婚。 |
| 集合 | Separable V-O (集 gather + 合 join) | Split: 集了合, 在操场集合. Mostly used as command/intransitive. | 八点在门口集合。 |

| 挂号 | Separable V-O (挂 hang + 号 number) | Split: 挂个号, 挂了号. Used at hospitals/post offices. | 我先去挂个号。 |

| 发言 | Separable V-O (发 issue + 言 speech) | Split: 发了言, 发过言. Topic via 关于. | 他在会上发了言。 |
| 罚款 | Separable V-O (罚 penalize + 款 sum) | Split: 罚了款, 罚了一百块款. | 警察罚了他二百块款。 |

| 签 / 签字 | 签 alone = sign; 签字 is the V-O form | Note 签字 is separable: 签了字, 签过字. | 请在这里签字。/ 他签了字。 |

## 2. Classical / Formal-Register Words

These appear mostly in writing, news, formal speech, set phrases, or legal language. Using them in casual chat sounds bookish or wrong. The semanticNote must include a register caveat.

| Simplified | Category | What the semanticNote MUST mention | Example use |
|---|---|---|---|
| 勿 | Classical negative imperative ("do not") | Written/formal only. Used on signs and in set phrases (请勿吸烟). Do NOT use in conversation; spoken equivalent is 别 or 不要. | 请勿吸烟。/ 闲人勿入。 |
| 乙 | Classical ordinal ("B / second") | Formal listing only — contracts, chemistry (乙醇), Party A/B (甲方乙方). Not used as "two" in counting. | 甲方与乙方签订合同。 |
| 甲 | Classical ordinal ("A / first") | Formal listing only — contracts, classifications, shells (指甲, 龟甲). Not used as "one" in counting. | 甲方负责设计。 |
| 则 | Classical conjunction/adverb ("then; in that case") + measure word for short pieces | Written register for "then": 不进则退. Also a measure word for news items, jokes, fables (一则新闻, 三则笑话). Spoken "then" is 就/那么. | 学而不思则罔。/ 一则消息 |
| 何必 | Rhetorical adverb ("why must / there's no need to") | Carries rhetorical/argumentative tone — implies the speaker thinks the action is unnecessary. Slightly formal, common in writing and earnest speech. | 你何必这么生气? |
| 何况 | Conjunction ("let alone / much less / moreover") | Formal-leaning. Often in 更何况 / 何况 ... 呢. Often paired with a 连...都 clause first. | 大人都做不到, 何况小孩呢? |
| 仿佛 | Comparative adverb ("as if / seemingly") | Literary register. Spoken equivalent is 好像. Use in descriptive prose, not casual chat. | 他仿佛听到了什么声音。 |
| 凡 | Classical adverb ("every / all that ...") | Formal/written. Usually in 凡是...都... or in fixed phrases (凡人, 大凡). Note: 凡 itself isn't on the HSK 5 list — included only if it appears as a component; flag as classical if encountered. | 凡是参加的人都得交钱。 |
| 倘若 | Classical conjunction ("if / supposing") | Written register. Spoken equivalent is 如果/要是. Note: not in this list; flag if encountered. | 倘若下雨, 比赛取消。 |
| 既然 | Conjunction ("since / now that") | Mid-formal; pairs with 就/那 in second clause. Common in both writing and serious speech. (Note: 既然 may be HSK 4; included for cross-list consistency.) | 既然你来了, 就坐下吧。 |
| 与其 | Comparative conjunction ("rather than") | Formal-leaning. ALWAYS paired: 与其 A, 不如 B ("rather than A, better B"). See section 5. | 与其等他, 不如自己去。 |
| 毕竟 | Adverb ("after all / when all is said") | Slightly formal/reflective. Often clause-initial or after subject. Useful in argumentation. | 他毕竟还是个孩子。 |
| 的确 | Adverb ("indeed / certainly") | Mid-formal. More emphatic than 真的; pairs with confirming a fact. | 这件事的确发生过。 |
| 居然 | Adverb ("unexpectedly / who would have thought") | Carries surprise/disbelief register. Stronger and more bookish than 竟然 alone — note speaker attitude. | 他居然没来! |
| 难免 | Adverb ("hard to avoid / inevitably") | Formal-leaning; often with 会. | 第一次难免会紧张。 |
| 未必 | Adverb ("not necessarily") | Formal-leaning; spoken equivalent is 不一定. | 他说的未必是真的。 |
| 至于 | Connector ("as for / as to") | Discourse marker, formal/written-leaning, used to shift topic. | 至于价格, 我们以后再谈。 |
| 至今 | Adverb ("up to now / to this day") | Formal/written register. Spoken equivalent is 到现在. | 这件事至今没有结果。 |
| 此外 | Discourse connector ("besides / in addition") | Written/formal. Spoken equivalent is 另外. | 此外, 还有几点说明。 |
| 从而 | Conjunction ("thereby / thus") | Strongly written register. Connects cause to result. | 他刻苦学习, 从而取得了好成绩。 |
| 因而 | Conjunction ("therefore / as a result") | Written register. Spoken equivalent is 所以. | 天气恶劣, 因而航班取消。 |
| 凭 | Preposition/verb ("rely on / based on") | Mid-formal. Common in 凭什么, 凭着, 凭借. | 凭什么相信你? / 凭经验判断 |
| 之 | Classical possessive/object marker | Appears as morpheme in compounds (总之, 之间, 之内, 之后). Not used standalone in modern speech. Flag whenever it appears as a component. | 总之 / 之前 |
| 所 | Classical relativizer + measure word + noun | Multi-function: relativizer (所认识的人), measure for buildings (一所学校, 三所医院), noun ("place"). Note ALL three uses. | 一所学校 / 我所知道的 |
| 某 | Indefinite determiner ("a certain / some") | Formal-leaning. Used in news/legal: 某人, 某地, 某公司. Spoken equivalent in casual: 某个 or just 一个. | 某公司发布了新产品。 |
| 一旦 | Conjunction ("once / as soon as") | Formal-leaning, often in hypothetical/warning contexts. Pairs with 就. | 一旦发生危险, 立刻报警。 |
| 一律 | Adverb ("uniformly / without exception") | Formal/regulatory register. Common on signs and policies. | 学生一律不准吸烟。 |
| 一致 | Adjective/adverb ("consistent / unanimous") | Formal-leaning when adverbial: 一致同意, 一致认为. | 大家一致同意这个方案。 |
| 一再 | Adverb ("repeatedly / again and again") | Formal-leaning; carries nuance of insistence. | 他一再强调安全问题。 |
| 善于 | V-complement ("be good at") | Formal/written. Spoken equivalent: 擅长 or 很会. | 他善于沟通。 |
| 属于 | Verb ("belong to") | Mid-formal; classifying/categorizing register. | 鲸鱼属于哺乳动物。 |
| 位于 | Verb ("be located at") | Written/geographical register. Spoken: 在. | 学校位于市中心。 |
| 在于 | Verb ("lie in / consist in") | Written/formal explanatory register. | 关键在于态度。 |
| 等于 | Verb ("equal / amount to") | Mid-formal in prose; neutral in math. Note both uses. | 二加二等于四。/ 不说话等于默认。 |
| 总之 | Discourse marker ("in short / in a word") | Written/formal-leaning summarizer. Contains classical 之. | 总之, 我们必须努力。 |
| 总算 | Adverb ("at last / finally") | Carries relief register — colloquial but with attitude. Different from neutral 终于. | 他总算来了! |
| 反正 | Adverb ("anyway / in any case") | Colloquial register — carries dismissive/resigned attitude. Flag as casual. | 反正我不去。 |
| 何必 | (listed above) | — | — |
| 难怪 | Adverb ("no wonder") | Conversational discovery marker. Note speaker realization tone. | 难怪他没来, 原来生病了。 |
| 怪不得 | Adverb ("no wonder") | Synonym of 难怪, slightly more colloquial. | 怪不得这么贵! |
| 据说 | Adverb ("it is said / reportedly") | Hearsay marker; news/written register but also spoken. Note evidentiality. | 据说他要辞职。 |
| 即将 (not in list) | — | — | — |

## 3. Bound Morphemes / Single-Character Entries

Single characters that don't stand alone freely as words in modern speech, OR that have multiple grammatical roles the example sentence must respect. The note must specify standalone status so example sentences embed the character correctly (in compounds, fixed phrases, or as one of its functioning roles).

| Simplified | Category | What the semanticNote MUST mention | Example use |
|---|---|---|---|
| 哎 | Interjection | Standalone exclamation only — surprise, mild protest, summoning. Never modifies anything. Sentence-initial. | 哎, 你看那个! |
| 唉 | Interjection | Standalone sigh — resignation/regret. Distinct from 哎 (surprise). | 唉, 真没办法。 |
| 嗯 | Interjection / response particle | Standalone response: yes/agreement (rising) or thinking (level). Never embedded. | 嗯, 我知道了。 |
| 呀 | Sentence-final particle / interjection | Variant of 啊 after vowels. Either softening sentence-final or surprised exclamation. NOT a standalone content word. | 你来了呀! |
| 喂 | Greeting interjection | Phone "hello"; also "hey" to summon someone (slightly rude). Standalone only. | 喂, 你好? / 喂, 等等! |
| 哈 | Interjection (laughter / triumphant) | Onomatopoeic laugh, often reduplicated 哈哈. Standalone. | 哈哈, 真有意思! |
| 岸 | Bound noun ("shore/bank") | Rare alone in modern speech. Compounds: 海岸, 河岸, 上岸, 对岸. | 河岸边有很多树。 |
| 暗 | Bound adj/morpheme ("dark / hidden") | Rarely standalone predicative; common in compounds: 黑暗, 暗号, 暗中. As predicate it works (天暗了). | 天慢慢暗了下来。 |
| 薄 | Adjective ("thin"); also reads bó in compounds | Stands alone as predicate ("thin"). Note two readings: báo (concrete thin) vs bó (abstract: 薄弱, 单薄, 薄情). | 这本书很薄。/ 薄弱 |
| 背 | Two readings/meanings: bèi (back, recite) / bēi (carry on back) | MUST disambiguate: 背 (bèi) noun "back" / verb "recite" (背课文); 背 (bēi) "carry on back" (背书包). Standalone in all senses. | 他背着书包。/ 他在背课文。 |
| 便 | Two readings: biàn (then/convenient/classical 就) / pián (in 便宜) | 便 (biàn) is a classical/written equivalent of 就; standalone is formal. 便 (pián) only in 便宜. Flag as register-marked. | 说完便走了。 (formal) |
| 布 | Bound noun ("cloth") | Standalone usage limited; compounds 棉布, 布料, 公布. As measure/noun for cloth it works alone. | 这块布很软。 |
| 册 | Measure word / bound noun | Measure for bound volumes/books: 一册书, 第三册. Also in 注册, 手册. NOT a free noun for "book" — flag as measure word. See section 4. | 这套书共五册。 |
| 朝 | Multi-function: zhāo (morning), cháo (toward / dynasty / face) | MUST disambiguate readings. cháo as preposition "toward" (朝东走); cháo as "dynasty" (唐朝); zhāo in 朝霞, 朝阳. | 朝东走 / 唐朝 |
| 趁 | Preposition ("taking advantage of / while") | Not a standalone verb — always preposition introducing a clause/NP: 趁热, 趁机会, 趁现在. Flag as preposition only. | 趁热吃吧! |
| 称 | Two readings: chēng (call/weigh) / chèn (suit/fit) | Disambiguate: chēng "call/refer to" (称为, 称呼); chēng "weigh" (称体重); chèn "fit/match" (相称, 称心). | 他称我老师。/ 称体重 |
| 冲 | Two readings: chōng (rush, brew) / chòng (facing, blunt) | chōng — rush/charge, brew tea/coffee, rinse (冲水). chòng — directional ("facing toward"), or adj ("blunt"). | 冲杯咖啡 / 冲我笑 |
| 丑 | Adjective ("ugly") + Earthly Branch | Mainly adj; also a Chinese zodiac/calendar branch (丑时, 丑牛). Standalone as adj is fine. | 他长得丑。 |
| 臭 | Adjective ("smelly / stinking") | Standalone adj. Also figurative/pejorative prefix (臭脾气, 臭毛病). Note negative connotation. | 这鱼臭了。/ 臭脾气 |
| 吹 | Verb ("blow / play wind instrument / brag / break off") | Standalone. Flag the "brag" sense (吹牛) and "fall through" sense (这事吹了) as colloquial extensions. | 风在吹。/ 别吹牛了。/ 这事吹了。 |
| 醋 | Noun ("vinegar / jealousy") | Standalone noun. Note metaphorical use: 吃醋 = jealous (in romantic context). Pedagogically important. | 加点醋。/ 她吃醋了。 |
| 催 | Verb ("urge / hurry someone") | Standalone transitive: 催他, 催我交作业. Note nuance of pressuring. | 妈妈催我快点。 |
| 淡 | Adjective ("light/bland/weak") | Standalone adj covering taste (淡), color (颜色淡), strength (淡茶), and emotion (冷淡). Multiple senses. | 这汤太淡了。/ 颜色很淡 |
| 滴 | Verb + measure word ("drip / drop") | Verb: drip. Measure: a drop of liquid (一滴水, 几滴泪). MUST list as both verb and measure word — see section 4. | 水在滴。/ 一滴水 |
| 顶 | Noun + verb + measure word | Noun: top (山顶, 屋顶). Verb: support/butt (用头顶). Measure: hats/things with tops (一顶帽子). MUST list all three; measure word use is the trickiest — see section 4. | 山顶 / 一顶帽子 / 顶住压力 |
| 冻 | Verb ("freeze") | Standalone. 冻 + complement: 冻坏, 冻僵, 冻死. Also noun (果冻 jelly). | 水冻成冰了。/ 冻坏了 |

## 5. Set Pair Conjunctions (Multi-Part Constructions)

These conjunctions almost always come with a fixed partner. The semanticNote must include the FULL paired construction so example sentences show both halves.

| Simplified | Category | What the semanticNote MUST mention | Example use |
|---|---|---|---|

| 除非 | Exclusive pair | Construction: 除非 A, 否则/不然 B / 才 B = "only if A; otherwise B" or "unless A, won't B." Always paired. | 除非你道歉, 否则我不原谅你。 |

## Summary of counts

- Separable verbs flagged: ~30 (this is the highest-stakes category — getting 结婚了三次 wrong is a real failure)
- Classical/formal-register entries: ~28
- Bound morphemes / multi-reading single chars: ~45
- Measure words and particles: ~21
- Paired conjunctions: ~10

Total entries needing special semanticNote handling: roughly 130 of 1,300 (~10%).

The remaining ~90% take plain definitions; the false-positive list above protects single-character verbs that look exotic but are actually free, plain words in modern usage.
